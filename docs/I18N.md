# 🌍 چندزبانه‌سازی + اتصال Hugging Face

## ۱) زبان‌ها

| زبان | کد | جهت | وضعیت |
| --- | --- | --- | --- |
| English | `en` | LTR | کامل |
| Türkçe | `tr` | LTR | رابط + صفحه‌ی خانه |
| فارسی | `fa` | **RTL** | رابط + صفحه‌ی خانه |
| العربية | `ar` | **RTL** | رابط + صفحه‌ی خانه |

**انتخاب زبان چطور کار می‌کند؟** به این ترتیب: `?lang=fa` در آدرس ← انتخاب قبلی کاربر (localStorage) ← زبان مرورگر ← انگلیسی.

* جابه‌جا‌کننده‌ی زبان در هدر (آیکون 🌐) و در منوی موبایل.
* آدرس اشتراکی می‌شود: `https://aqmx.atikova.com/?lang=ar#/cities`
* `<html lang>` و `<html dir>` خودکار تنظیم می‌شوند؛ در فارسی و عربی **کل چیدمان راست‌به‌چپ** می‌شود (هدر، فوتر، جدول‌ها، دکمه‌ها).
* کلیدهای ترجمه: `app/src/i18n/strings.ts` — افزودن زبان = یک بلوک تازه + یک خط در `LANGS`.

**چه چیزی ترجمه شده و چه چیزی نه؟** رابط کامل (منو، هدر، فوتر، دکمه‌ها، هشدارها) + **کل صفحه‌ی خانه**.
داده‌های محتوایی (پروفایل ۲۰ شهر، ۱۲ دامنه‌ی راهنما، بریف نوآوری‌ها، جدول نمایشگاه) **به انگلیسی** می‌مانند و
روی صفحه‌های غیرانگلیسی نوار «محتوای صفحه‌ها انگلیسی است؛ رابط ترجمه شده» نمایش داده می‌شود — تا هیچ‌جا نیمه‌ترجمه به‌نظر نرسد.

## ۲) اتصال Hugging Face (API)

| مسیر | کار |
| --- | --- |
| `GET /api/hf/status` | وضعیت واقعی توکن: نام کاربر، scopeها، وضعیت دیتاست، و **آیا اجازه‌ی Inference دارد یا نه** |
| `GET /api/hf/status?probe=1` | همان + یک فراخوانی آزمایشی کوچک به Router برای سنجش دقیق مجوز |
| `GET /api/hf/kb` | **دانش‌نامه را از دیتاست HF می‌خواند** و در KV می‌گذارد (`check=1` فقط بررسی می‌کند) |
| `POST /api/chat` | زنجیره‌ی ارائه‌دهنده: Workers AI → **HF Inference Providers** → پاسخ بازیابی‌محور. فیلد `kbSource` می‌گوید پاسخ از کدام نسخه‌ی دانش‌نامه آمده |

**نکته‌ی مهم:** بعد از یک‌بار صدا زدن `/api/hf/kb`، دستیار **از نسخه‌ی روی Hugging Face** پاسخ می‌دهد
(`kbSource: huggingface-dataset`). یعنی دانش‌نامه را روی HF به‌روز کنید و سایت بدون دیپلوی تازه از آن استفاده می‌کند.

### چه چیزی همین حالا کار می‌کند
* ✅ خواندن/نوشتن دیتاست و مخزن (`repo.write`)
* ✅ شمردن و کشیدن دانش‌نامه از دیتاست (تست‌شده: ۱۱۴ چانک، ۱۱۶ کیلوبایت)
* ✅ پاسخ‌دادن دستیار از همان نسخه

### چه چیزی اجازه ندارد
* ❌ **Inference Providers** با توکن فعلی: `403 — This authentication method does not have sufficient permissions`
* ❌ ساخت **Space گرادیو** برای ماژول AI: `402 Payment Required` (سهمیه‌ی CPU رایگان تمام است یا نیاز به PRO دارد)

### چطور فعال می‌شود (۲ دقیقه، سمت شما)
1. https://huggingface.co/settings/tokens → New token → نقش **Write**+ تیک **«Make calls to Inference Providers»**
2. توکن را بدهید تا در `HF_TOKEN` بگذارم (یا خودتان: `cd worker && npx wrangler secret put HF_TOKEN`)
3. بعد از آن `/api/hf/status?probe=1` باید `permitted: true` بدهد و دستیار با مدل HF
   (`Qwen/Qwen2.5-7B-Instruct`) جواب بدهد — بدون هیچ تغییر دیگری.
